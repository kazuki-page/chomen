# oyasan-app

賃貸マンションの入居者管理・修繕管理アプリ。

実家で所有する賃貸マンション（1棟40室・駐車場5台）の管理業務を対象とした Web アプリケーション（PWA）。
現在 Notion で運用している業務を置き換えることを目的とする。

## 解決したい課題

現行の Notion 運用には次の課題がある。

- データベースビューが起点のため、**「今何をすべきか」を画面が教えてくれない**（主な操作者は50代）
- 正しい操作に**運用マニュアルの参照が必要**
- 入居確定時に空室を「過去」にする、入居完了時に更新レコードを作る等、**付随作業がすべて人力**
- 同じ「ステータス」列に `進行中/完了/未/準備中/現在/過去` が混在し、**意味が文脈依存**
- **修繕案件の進行状況が追えず、放置に気づけない**

## アプローチ

- 運用マニュアルの手順を**アプリ側に埋め込み、マニュアルを不要にする**
- 「空室」「現在の家賃」を保存せず**導出値**とし、手作業の連鎖を消す
- 修繕は工程を細分化せず、**「誰がやる」「今誰待ち」**の2点と放置検知に絞る

## 技術スタック

| レイヤー | 採用 |
|---|---|
| フレームワーク | React Router v8（framework mode） |
| 実行環境 | Cloudflare Workers |
| ビルド | Vite + `@cloudflare/vite-plugin` |
| スタイル | Tailwind CSS v4 |
| DB | Cloudflare D1 (SQLite) + Drizzle ORM |
| ストレージ | Cloudflare R2 |
| 認証 | Better Auth（招待制） |

## セットアップ

```bash
npm install
cp .dev.vars.example .dev.vars   # BETTER_AUTH_SECRET を設定
npm run db:migrate               # ローカル D1 にスキーマを適用
npm run db:seed                  # 架空のデモデータを投入
npm run dev
```

初回は `/signup` から最初のアカウント（管理者）を作成する。
以降のユーザーは設定画面から発行する招待リンク経由でのみ登録できる。
